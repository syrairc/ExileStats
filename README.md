# ExileStats

Plugin that tracks per-area combat statistics and logs them to disk for later review.

## Features

- Monster counter (on-screen, by rarity)
- Per-area JSON logs: monsters, loot, pickups, player path, snapshots, deaths, content sightings
- Map content detection and state tracking (rituals, expeditions, strongboxes, etc.)
- Exploration coverage calculation
- Account net worth tracking via stash scan
- In-game statistics window with run history, graphs, and activity reports

## Requirements

Map image capture and SVG-based map rendering require this [Radar fork](https://github.com/syrairc/Radar). The plugin functions without it but the map view will be unavailable.
